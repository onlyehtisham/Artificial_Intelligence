# Introduction to Artificial Intelligence

Welcome to the course repository for **Introduction to Artificial Intelligence**.

This repository contains course materials, lecture notes, Python examples, practical exercises, assignments, project resources, and other learning materials designed to provide a strong foundation in Artificial Intelligence and its modern applications.

## 📚 Course Overview

This course introduces the fundamental concepts, techniques, algorithms, and applications of Artificial Intelligence. It covers both classical AI approaches and modern data-driven AI techniques through a combination of conceptual learning, problem-solving, Python programming, and project-based activities.

Students will gradually progress from basic AI concepts to search algorithms, knowledge representation, reasoning, machine learning, neural networks, NLP, computer vision, generative AI, and responsible AI.

## 🎯 Learning Objectives

By completing this course, students should be able to:

* Understand fundamental concepts of Artificial Intelligence.
* Explain intelligent agents and AI environments.
* Formulate problems using state-space representation.
* Implement classical AI search algorithms using Python.
* Apply heuristic and adversarial search techniques.
* Understand knowledge representation and logical reasoning.
* Apply probability and reasoning under uncertainty.
* Understand fundamental Machine Learning concepts.
* Build and evaluate basic Machine Learning models.
* Understand the fundamentals of neural networks.
* Explore NLP, computer vision, and generative AI.
* Evaluate AI systems from technical and ethical perspectives.
* Develop a Python-based AI application as a group project.

## 📖 Course Topics

The repository covers the following major areas:

1. Foundations of Artificial Intelligence

13. Unsupervised Learning

15. Natural Language Processing
16. Computer Vision
17. Generative AI
18. Responsible and Ethical AI
19. AI Project Development
